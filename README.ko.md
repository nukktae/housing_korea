# 부동산 매물 알림 봇 사용법

다방과 직방에서 조건에 맞는 매물이 올라오면 텔레그램으로 자동 알림을 보내주는 봇이다. GitHub Actions 위에서 돌아가기 때문에 노트북을 꺼둬도 20분마다 알아서 새 매물을 확인한다.

이 문서는 저장소를 처음 받아서 본인 조건(지역, 보증금, 월세 등)에 맞게 설정하고, 본인 텔레그램으로 알림을 받기까지의 전체 과정을 다룬다.

## 전체 흐름

1. 저장소를 내 계정으로 복사한다 (포크).
2. 텔레그램 봇을 새로 만든다.
3. `config.json`에서 원하는 조건(지역, 가격, 평수 등)을 수정한다.
4. GitHub 저장소에 텔레그램 토큰을 비밀값(secret)으로 등록한다.
5. GitHub Actions를 켜서 자동 실행되게 한다.

## 1. 저장소 포크하기

원본 저장소 페이지에서 오른쪽 위 **Fork** 버튼을 누른다. 그러면 내 GitHub 계정 밑에 똑같은 저장소가 복사된다. 이후 모든 설정은 이 포크한 저장소에서 진행한다.

원본 코드가 업데이트되면 가끔 내 포크에도 반영하고 싶을 수 있는데, 그건 GitHub의 **Sync fork** 버튼으로 나중에 언제든 할 수 있다.

## 2. 텔레그램 봇 만들기

1. 텔레그램 앱에서 `@BotFather`를 검색해서 대화를 연다.
2. `/newbot` 명령을 보낸다.
3. 봇 이름과 아이디(예: `mymove_alert_bot`)를 순서대로 입력한다.
4. BotFather가 토큰을 준다. `123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx` 같은 형태다. 이게 `TELEGRAM_BOT_TOKEN`이다.

이제 채팅 ID를 알아내야 한다. 봇은 만들었지만 아직 나와 대화한 적이 없어서 채팅 ID가 없는 상태다.

5. 방금 만든 봇을 텔레그램에서 검색해 아무 메시지나 하나 보낸다 (예: "안녕").
6. 브라우저에서 아래 주소를 여는데, `<토큰>` 자리에 4번에서 받은 토큰을 넣는다.

   ```
   https://api.telegram.org/bot<토큰>/getUpdates
   ```

7. 결과로 나오는 JSON 안에서 `"chat":{"id":123456789, ...}` 부분을 찾는다. 이 숫자가 `TELEGRAM_CHAT_ID`다.

혼자 받는 게 아니라 그룹으로 여러 명이 같이 받고 싶으면, 봇을 텔레그램 그룹에 초대하고 그룹에서 메시지를 하나 보낸 다음 같은 방법으로 `getUpdates`를 확인하면 된다. 이때 채팅 ID는 마이너스(-) 부호가 붙은 숫자로 나온다.

## 3. 조건 설정하기 (`config.json`)

저장소 루트에 있는 `config.json` 파일을 열어서 본인 조건에 맞게 고친다. 가격, 지역, 매물 종류 같은 필터가 전부 여기 모여 있어서 코드는 건드릴 필요가 없다.

### 가격/평수 조건

```json
"filters": {
  "depositMaxManwon": 500,
  "depositMinManwon": 100,
  "monthlyRentMaxManwon": 68,
  "minimumPyeong": 6,
  ...
}
```

- `depositMaxManwon` / `depositMinManwon`: 보증금 상한/하한 (만원 단위)
- `monthlyRentMaxManwon`: 월세 상한 (만원 단위)
- `minimumPyeong`: 최소 평수

숫자만 원하는 값으로 바꾸면 된다.

### 매물 종류, 제외할 층

```json
"roomTypes": ["원룸", "오피스텔"],
"excludedFloors": ["반지하", "옥탑"],
```

원룸/오피스텔 외에 다른 종류를 찾고 싶거나, 반지하도 괜찮다면 이 배열을 수정한다.

### 지역 제외 목록

```json
"excludedAreas": ["관악구", "서초구", ...]
```

여기 적힌 동/구는 검색 결과에서 아예 빠진다. 관심 없는 동네를 여기에 추가하고, 반대로 원래 빠져 있던 동네인데 보고 싶다면 목록에서 지워준다.

### 검색 범위 (서울 밖 지역으로 바꾸고 싶을 때)

```json
"location": {
  "name": "Seoul",
  "bbox": {
    "sw": { "lat": 37.425, "lng": 126.764 },
    "ne": { "lat": 37.701, "lng": 127.183 }
  },
  ...
}
```

지금은 서울 전역으로 잡혀 있다. 다른 도시로 바꾸려면 `bbox`(검색 사각 영역)의 위도/경도를 그 도시 범위로 바꿔야 하는데, 이 부분은 좌표를 다루는 작업이라 손이 좀 간다. 필요하면 나한테 말해달라, 좌표만 뽑아서 넣어주면 된다.

### 전입신고 문구 필터

```json
"registrationPositiveWords": ["전입"],
"registrationNegativeWords": ["전입불가", "전입 불가", ...]
```

매물 설명에 "전입" 관련 단어가 있는지, 그리고 "전입불가" 같은 부정 표현이 있는지로 걸러낸다. 그대로 둬도 무방하다.

수정이 끝나면 저장하고, GitHub 웹사이트에서 바로 커밋하거나 로컬에서 커밋 후 푸시한다.

## 4. GitHub에 텔레그램 정보 등록하기 (Secrets)

토큰과 채팅 ID는 코드에 직접 적으면 안 되고, GitHub의 비밀값 저장 기능을 써야 한다.

1. 내 포크 저장소 페이지에서 **Settings** 탭으로 들어간다.
2. 왼쪽 메뉴에서 **Secrets and variables** → **Actions**를 클릭한다.
3. **New repository secret** 버튼을 누른다.
4. 아래 두 개를 각각 하나씩 추가한다.

   | 이름 (Name) | 값 (Value) |
   |---|---|
   | `TELEGRAM_BOT_TOKEN` | 2번 과정에서 받은 봇 토큰 |
   | `TELEGRAM_CHAT_ID` | 2번 과정에서 알아낸 채팅 ID |

이 값들은 저장소 관리자만 볼 수 있고, 코드나 로그에는 노출되지 않는다.

## 5. GitHub Actions 켜기

포크한 직후에는 GitHub Actions가 기본적으로 꺼져 있는 경우가 많다.

1. 저장소의 **Actions** 탭으로 들어간다.
2. "Workflows aren't being run on this forked repository" 같은 안내가 보이면 초록색 버튼을 눌러서 활성화한다.
3. **Settings** → **Actions** → **General**로 들어가서 **Workflow permissions** 항목을 **Read and write permissions**로 바꾸고 저장한다. (봇이 확인한 매물 목록을 저장소에 커밋하기 때문에 쓰기 권한이 필요하다.)
4. 다시 **Actions** 탭으로 가서 왼쪽에서 **Housing Telegram Bot** 워크플로를 선택하고, **Run workflow** 버튼으로 한 번 수동 실행해본다.

첫 실행은 지금 조건에 맞는 매물을 전부 "확인함"으로 기록만 하고 텔레그램 메시지는 보내지 않는다. 그래야 처음부터 수백 개 메시지가 쏟아지는 걸 막을 수 있다. 이후 20분마다 자동 실행되면서, 그 사이에 새로 올라온 매물만 알림으로 보낸다.

## 6. 정상 작동 확인

1. **Actions** 탭에서 실행 기록이 초록색 체크(성공)로 뜨는지 확인한다. 빨간색 X가 뜨면 로그를 열어서 어떤 단계에서 실패했는지 본다.
2. 20분 정도 기다린 뒤 텔레그램에 새 매물 알림이 오는지 확인한다. (해당 시간에 조건에 맞는 새 매물이 없으면 당연히 메시지가 안 온다. 조급해하지 않아도 된다.)

## 로컬에서 미리 테스트하고 싶을 때 (선택)

GitHub에 올리기 전에 내 컴퓨터에서 먼저 돌려보고 싶다면:

```bash
npm install
npx playwright install chromium
cp .env.example .env
```

`.env` 파일을 열어서 `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`를 채운 다음:

```bash
npm run dry-run
```

이 명령은 텔레그램으로 실제 메시지를 보내지 않고, 어떤 매물이 걸리는지 터미널에만 출력해준다. 조건을 이것저것 바꿔볼 때 유용하다.

## 자주 막히는 부분

- **Actions가 초록불인데 메시지가 안 온다**: 조건에 맞는 새 매물이 그 사이에 없었을 가능성이 높다. `excludedAreas`에 원하는 동네를 실수로 넣어놨는지도 확인해보자.
- **Actions가 빨간불(실패)이다**: 대부분 `TELEGRAM_BOT_TOKEN` 또는 `TELEGRAM_CHAT_ID`를 잘못 입력했거나, Secrets 등록을 빼먹은 경우다. 로그의 에러 메시지를 확인한다.
- **채팅 ID를 못 찾겠다**: 봇한테 먼저 메시지를 보내지 않으면 `getUpdates`에 아무것도 안 뜬다. 순서(봇에게 먼저 말 걸기 → `getUpdates` 확인)를 지켜야 한다.
- **너무 많은 매물이 한꺼번에 온다**: `excludedAreas`나 가격 조건을 더 좁게 잡으면 된다.
